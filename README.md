## Install

The installation procedure is organized by server and client guides.
Each guide includes both installation and configuration, and covers all
supported authentication methods.

* [Install and Configure SQC Scheduler(Server)](docs/INSTALL_SERVER.md)
* [Install and Configure SQC Scheduler(Client)](docs/INSTALL_CLIENT.md)

One running process of the SQC scheduler can handle multiple combinations
of an RPC protocol and an authentication method listed above.
However, other combinations (e.g. gRPC with mutual TLS authentication)
are not supported.
